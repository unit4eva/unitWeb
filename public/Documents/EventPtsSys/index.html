  • UNIT-LARP Basic training does not grant any points
  • Joined only for Bunker/Lab = +3 pts (for the whole event)
  • If adding a multiplier, round down (for example ⌊1.62⌋ = 1). Multiplier can only be added after approval of an Oversight Committee member
  • ‘x Division only event’ will be counted as RGE event point system, and point cap is 7pts
  • Abusing the point system will lead to host perm being removed and all events where the system was abused will become null and void
